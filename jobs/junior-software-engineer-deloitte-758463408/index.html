What will your typical day look like?

We’re looking for a Junior Software Engineer to support the development of scalable applications and services.
This is an entry-level, hands-on role focused on learning, building, and contributing to team delivery. The role emphasizes strong coding fundamentals, development best practices, and exposure to modern tools and AIassisted workflows.

About the team

Frontier Engineering is a specialized innovation and delivery acceleration team focused on transforming
architecture and business requirements into working solutions using generative AI and modern engineering
practices.
The team leads the initial build phase of strategic initiatives, rapidly developing prototypes, proof-of-concepts, and production-ready foundations while embedding best practices for agentic development, AI-assisted software engineering, automation, security, and quality. By establishing reusable patterns, reference implementations, and delivery accelerators, Frontier Engineering enables delivery teams to scale solutions faster, reduce risk, and maximize the value of AI-driven development.

Enough about us, let’s talk about you

Key Responsibilities

  • Develop and maintain features under guidance from senior engineers
  • Write clean, readable, and testable code
  • Assist in building APIs, services, and frontend components
  • Participate in debugging, testing, and troubleshooting issues
  • Learn and apply development best practices and coding standards
  • Collaborate with team members during design and implementation
  • Use AI tools and modern development workflows to improve productivity
  • Contribute to documentation and technical artifacts as needed

Required Experience

  • 2+ years of software development experience
  • Understanding of programming concepts and data structures
  • Exposure to full-stack technologies
  • Exposure to cloud platforms or modern development tools
  • Familiarity with at least one programming language (e.g., Typescript, .NET with SQL, etc.)
  • Exposure to web development fundamentals (frontend, backend, APIs)
  • Basic understanding of version control (e.g., Git)
  • Strong willingness to learn and adapt
  • Familiarity with APIs or basic integration concepts
  • Experience using AI tools (e.g., GitHub Copilot, ChatGPT) in development
  • Strong communication and collaboration skills
