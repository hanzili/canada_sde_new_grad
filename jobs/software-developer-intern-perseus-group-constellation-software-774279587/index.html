Full Description

THE POSITION

The successful Software Developer Intern works in our Markham, Ontario office and reports to our Solutions Architect for the homebuilding industry's leading-edge enterprise software product.

The Software Developer Intern works in a Scrum team to build high-performing, resilient, and manageable web-based ERP software for homebuilders, using AI-assisted development throughout the SDLC. Responsibilities include:

  • Study and understand the application's functionality, workflow, and design.
  • Work with the team to build a new product module end-to-end using AI-assisted development tools under architectural guidance.
  • Assist in setting up, testing, and maintaining MCP servers/connectors that power AI-assisted development for the team, including configuration, documentation, and usage governance.
  • Expand automated test coverage — unit, integration, and end-to-end (Playwright) — and wire tests into Azure DevOps CI/CD pipelines.
  • Author and refine reusable AI context: rules files, prompts, and agentic workflows for repeatable development and review tasks.
  • Evaluate the quality and reliability of AI-assisted output against real coding tasks; iterate to improve.
  • Document processes and provide recommendations for scaling AI-assisted development and automation across the team.

QUALIFICATIONS AND SKILLS

  • Able to work from the Markham, Ontario office.
  • Understanding of software requirements and the software development lifecycle.
  • Experience building multi-tier, distributed web solutions with an emphasis on Responsive Design.
  • Understanding of development best practices in a multi-developer team using a shared code repository (Git): branching, pull requests, code review.
  • Hands-on experience in full-stack development:
  • HTML5, TypeScript, JavaScript, stylesheets (Angular an asset)
  • .NET
  • SQL query
  • Object-Oriented Design
  • Test-Driven Development; ability to write unit and integration tests
  • Familiarity with AI coding assistants and prompt engineering (asset).
  • Exposure to test automation frameworks such as Playwright (asset).
  • Exposure to Azure DevOps (Repos, Pipelines) (asset).
