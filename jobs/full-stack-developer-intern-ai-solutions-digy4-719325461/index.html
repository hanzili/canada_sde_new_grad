Full Description

Location : Greater Toronto Area, Canada

Job Type : Full Time Summer Internship (3- 4 months)

Experience Level : No experience required

About Digy4

At Digy4, we are dedicated to pushing the boundaries of digital transformation by building scalable, high-performance AI-powered SaaS solutions that empower businesses. Our team thrives on collaboration, innovation, and a shared commitment to delivering modern software products that solve real-world challenges.

We are looking for a passionate Full Stack Developer Intern with an interest in Artificial Intelligence and Generative AI to join our engineering team. This internship offers hands-on experience working on cloud-native applications, AI-powered solutions, and modern web technologies in a fast-paced SaaS environment.

Role Overview

As a Full Stack Developer Intern at Digy4, you will work alongside experienced engineers to develop, test, and deploy AI-enabled applications. You will contribute to both front-end and back-end development while learning how modern AI technologies can be integrated into enterprise software products.

You will gain practical exposure to technologies such as Node.js, Java, React, AWS, Large Language Models (LLMs), MCP, AI APIs, and cloud-native architectures .

Key Responsibilities

Full Stack Development

  • Assist in designing and developing web applications using modern front-end and back-end technologies.
  • Develop and maintain RESTful APIs using Node.js and Java .
  • Build responsive user interfaces using React and modern JavaScript frameworks.
  • Support database design and development using DynamoDB and other cloud-based storage solutions.
  • Participate in debugging, troubleshooting, and performance optimization activities.

AI & Generative AI Development

  • Assist in integrating AI services and LLM APIs into web applications using MCP
  • Develop AI-powered features such as chatbots, document assistants, semantic search, and workflow automation tools.
  • Experiment with prompt engineering techniques to improve AI responses.
  • Support the implementation of MCP AND/OR Retrieval-Augmented Generation (RAG) solutions using vector databases and knowledge retrieval systems.
  • Research emerging AI technologies and contribute innovative ideas to product development.

Cloud & DevOps

  • Work with AWS services including:
  • Lambda
  • API Gateway
  • DynamoDB
  • S3
  • CloudWatch
  • Assist in deploying and monitoring applications in cloud environments.
  • Contribute to CI/CD pipelines and development automation processes.

Software Quality & Collaboration

  • Write unit and integration tests to ensure software quality.
  • Participate in code reviews and follow engineering best practices.
  • Collaborate with product managers, designers, and senior engineers to deliver product features.
  • Document technical solutions and development processes.

Required Skills & Qualifications

  • Currently pursuing or recently completed a degree in:
  • Computer Science
  • Software Engineering
  • Information Technology
  • Artificial Intelligence
  • Related technical field
  • Strong programming fundamentals and problem-solving skills.
  • Knowledge of JavaScript/TypeScript and object-oriented programming concepts.
  • Basic experience with Node.js and/or Java .
  • Familiarity with HTML, CSS, and modern front-end frameworks such as React .
  • Understanding of REST APIs and web application architecture.
  • Experience using Git for version control.
  • Strong communication and teamwork skills.
  • Passion for learning new technologies and solving complex problems.

Preferred Qualifications

  • Familiarity with AWS cloud services.
  • Exposure to Generative AI platforms such as OpenAI, Claude, Gemini, or AWS Bedrock.
  • Understanding of prompt engineering concepts.
  • Knowledge of vector databases, embeddings, or RAG architectures.
  • Experience with personal, academic, or open-source AI projects.
  • Familiarity with Docker and containerized applications.
  • Understanding of software testing and CI/CD concepts.

What You'll Gain

  • Real-world experience building AI-powered SaaS products.
  • Mentorship from experienced Full Stack and AI engineers.
  • Exposure to cloud-native architectures and modern development practices.
  • Hands-on experience with Generative AI, LLMs, and enterprise software development.
  • Opportunity to contribute to production-grade applications used by real customers.

Join Digy4 and help build the next generation of AI-powered software solutions
