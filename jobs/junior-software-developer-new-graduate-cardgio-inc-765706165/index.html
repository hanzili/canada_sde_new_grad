Full Description

Overview

We are seeking a motivated Junior Software Developer who is a recent graduate eager to kick-start their career in software development. Must be a Canadian citizen. This entry-level role offers an excellent opportunity to work on innovative projects within a dynamic team environment. The ideal candidate will have a passion for coding, learning new technologies, and contributing to the development of scalable applications. This position provides hands-on experience across various facets of software engineering, including web development, application design, and cloud integration.

Responsibilities

  • Assist in designing, developing, and maintaining web applications using technologies such as JavaScript, Ruby on Rails, C++ and C#.
  • Contribute to backend development tasks involving SQL databases like MySQL and SQL Server, ensuring efficient data management.
  • Collaborate with cross-functional teams to implement RESTful APIs and integrate third-party services.
  • Support application development efforts utilizing languages such as Java, Python, C++, and VBA.
  • Participate in Agile development cycles, including sprint planning, stand-ups, and code reviews.
  • Use version control systems like GitHub, SVN, and Git to manage code repositories effectively.
  • Work with cloud platforms such as AWS and Azure to deploy and manage applications.
  • Engage in front-end development tasks involving HTML, CSS, and front-end frameworks as needed.
  • Assist in troubleshooting issues and performing code testing to ensure software quality.
  • Maintain documentation of code changes and technical specifications for future reference.

Skills

  • Foundational knowledge of web development and application development principles.
  • Experience with SQL, MySQL, or similar relational databases.
  • Familiarity with cloud platforms such as AWS or Azure for deployment and management.
  • Understanding of REST APIs, GitHub, Git, SVN, and version control best practices.
  • Programming proficiency in languages including Java, Python, C#, C++, Ruby on Rails, and VBA is preferred.
  • Exposure to front-end technologies like HTML, CSS, JavaScript, and frameworks is a plus.
  • Knowledge of operating systems such as Linux is advantageous.
  • Experience with software development methodologies like Agile is desirable.
  • Ability to work collaboratively within a team environment while managing multiple priorities effectively.

This role is ideal for recent graduates passionate about software engineering who are eager to develop their skills in a supportive environment while contributing to impactful projects.

Pay: $25.00-$27.00 per hour

Benefits:

  • Flexible schedule

Work Location: Hybrid remote in Calgary, AB
