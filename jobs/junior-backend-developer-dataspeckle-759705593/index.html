We're Hiring

Junior Backend Engineer (Eligible for IRAP Programs)

  • Today
  • IRAP
  • British Columbia

Description DataSpeckle is a leading provider of conversational AI chatbot solutions for clinics, offering personalized and cost-effective healthcare support. Our flagship product, Effie, combines linguistic capabilities with machine learning to provide powerful insights and data ownership. Effie leverages generative AI algorithms to create highly conversational and engaging chatbots that offer services such as triage, appointment scheduling, seamless integration, and privacy compliance. Our platform relies on backend technologies such as PostgreSQL, Elasticsearch, and Python for data management and analysis.

DataSpeckle is seeking a talented and motivated Junior Backend Engineer with a focus on machine learning to join our dynamic team. As a key member of the development team, you will work closely with machine learning engineers to design and implement backend solutions for data extraction, filtering, and report generation.

Responsibilities

  • Collaborate with machine learning engineers to design and implement backend solutions for data extraction and manipulation.
  • Design and generate database architecture using PostgreSQL to support efficient data storage and retrieval.
  • Work closely with UI engineers to integrate backend functionalities into the frontend interface.
  • Develop search algorithms using Elasticsearch to extract relevant data from the database.
  • Implement filtering mechanisms to refine data queries based on user requirements.
  • Generate reports and PDF documents based on filtered data using Python programming.
  • Ensure the security, scalability, and performance of backend systems.
  • Conduct code reviews and provide feedback to ensure code quality and maintainability.
  • Stay updated on industry best practices and emerging technologies in backend development and machine learning.

Qualifications

  • Bachelor's degree in Computer Science, Engineering, or related field.
  • Proficiency in Python programming and backend development.
  • Strong knowledge of PostgreSQL database management.
  • Experience with Elasticsearch or similar search algorithms is a plus.
  • Familiarity with report generation and PDF manipulation libraries in Python.
  • Strong problem-solving skills and attention to detail.
  • Ability to work collaboratively in a team environment and communicate effectively with cross-functional teams.
  • Motivated to learn and adapt to new technologies and methodologies.

DataSpeckle is committed to a work environment in which all individuals are treated with respect and dignity.
