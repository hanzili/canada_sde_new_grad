About NRTH Health

Healthcare tech startup with AI-driven care

Full Description

Company Description NRTH Health is a next-generation healthcare platform that uses artificial intelligence to deliver faster, smarter, and more personalized care. Designed for a mobile-first world, it connects patients with licensed healthcare professionals through secure virtual appointments without waiting rooms or long lines. The company focuses on making healthcare radically accessible in Canada by combining clinical expertise with AI-driven tools. Key features include on-demand virtual visits, AI-powered symptom checking and triage, instant prescription refills, personalized health insights, and a secure, HIPAA-compliant platform. NRTH Health is rethinking the healthcare experience from the ground up, using AI to reduce wait times, improve diagnostic accuracy, and support clinicians with better data.

Role Description This remote internship role for an iOS Developer Intern involves contributing to the design, development, and testing of NRTH Health’s mobile applications for iOS. The intern will work with the engineering team to implement new features, refine user interfaces, fix bugs, and optimize performance for a mobile-first healthcare experience. Day-to-day tasks include writing clean, maintainable Swift code, integrating APIs, ensuring app security and reliability, and participating in code reviews. The intern will collaborate with product and design teams to translate requirements into functional app components and help improve the overall user experience. This is a structured internship role offering mentorship, exposure to AI-driven healthcare products, and practical experience in shipping real-world mobile solutions.

Qualifications

  • Strong foundation in Software Development principles and practices, including object-oriented programming and version control (e.g., Git).
  • Skills in iOS Development and iOS frameworks, with experience building or contributing to iOS applications.
  • Understanding of Mobile Application Development and Mobile Applications lifecycle, including testing, debugging, and deployment.
  • Familiarity with Swift and Xcode, and ability to work with RESTful APIs and JSON data.
  • Currently pursuing or recently completed a degree in Computer Science, Software Engineering, or a related field, or equivalent practical experience.
  • Ability to work effectively in a remote environment, communicate clearly, and collaborate in cross-functional teams.
  • Interest in healthcare technology, AI-driven products, and building user-centered mobile experiences.
  • Experience with basic UI/UX principles, unit testing, or App Store submission processes is an asset.
