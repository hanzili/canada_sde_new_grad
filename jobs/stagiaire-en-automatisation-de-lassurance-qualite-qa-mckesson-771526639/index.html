Description du poste

À titre de stagiaire en automatisation de l’assurance qualité (QA), vous contribuerez à la qualité et à la fiabilité de nos plateformes numériques B2C en concevant et en mettant en œuvre des tests automatisés pour les applications Web et mobiles. Vous utiliserez des outils de développement alimentés par l’intelligence artificielle, tels que GitHub Copilot et Claude Code, afin d’accélérer le développement de l’automatisation des tests, d’améliorer la couverture des tests et d’augmenter l’efficacité des livraisons.

Vous travaillerez également avec Kobiton, une plateforme de tests mobiles, pour valider les applications sur de vrais appareils et différentes configurations de systèmes d’exploitation. En collaboration étroite avec les équipes d’assurance qualité, de développement et de DevOps, vous acquerrez une expérience pratique en automatisation des tests, en intégration et déploiement continus (CI/CD), en tests mobiles et en ingénierie logicielle assistée par l’IA.

Responsabilités

  • Concevoir, développer et maintenir des scripts de tests automatisés pour des applications Web et mobiles.
  • Utiliser GitHub Copilot et Claude Code pour accélérer la création, l’optimisation et la maintenance des scripts de tests automatisés.
  • Réaliser des tests d’applications mobiles à l’aide de Kobiton sur différents appareils réels, systèmes d’exploitation et configurations.
  • Intégrer les suites de tests automatisés aux pipelines CI/CD afin de permettre des tests continus et un retour d’information plus rapide.
  • Collaborer avec les développeurs et les analystes QA pour identifier, reproduire et résoudre les anomalies logicielles.
  • Analyser les résultats des tests, enquêter sur les échecs et documenter clairement les constatations.
  • Soutenir les activités de tests de régression, fonctionnels, de fumée (smoke tests) et de bout en bout (end-to-end).
  • Contribuer à l’amélioration des cadres d’automatisation, des normes et des meilleures pratiques en matière de tests.
  • Documenter les scénarios de tests, les approches d’automatisation et les leçons apprises.
  • Explorer continuellement les nouveaux outils d’IA et les meilleures pratiques en ingénierie de la qualité afin d’améliorer l’efficacité et la couverture des tests.

Job Description

As a QA Automation Engineer Intern, you will contribute to the quality and reliability of our digital B2C platforms by designing and implementing automated tests for web and mobile applications. You will leverage AI-powered development tools such as GitHub Copilot and Claude Code to accelerate test automation development, improve test coverage, and increase delivery efficiency.

You will also work with Kobiton, a mobile device testing platform, to validate applications across real devices and operating system configurations. Working closely with QA engineers, developers, and DevOps teams, you will gain hands-on experience in test automation, continuous integration and continuous delivery, mobile testing, and AI-assisted software engineering.

Responsibilities

  • Design, develop, and maintain automated test scripts for web and mobile applications.
  • Use GitHub Copilot and Claude Code to accelerate the creation, optimization, and maintenance of automated test scripts.
  • Execute mobile application testing using Kobiton across multiple real devices, operating systems, and configurations.
  • Integrate automated test suites into CI/CD pipelines to enable continuous testing and faster feedback.
  • Collaborate with developers and QA engineers to identify, reproduce, and resolve software defects.
  • Analyze test results, investigate failures, and document findings clearly.
  • Support regression, functional, smoke, and end-to-end testing activities.
  • Contribute to improving test automation frameworks, standards, and best practices.
  • Document test scenarios, automation approaches, and lessons learned.
  • Continuously explore emerging AI tools and quality engineering practices to improve testing efficiency and coverage.

Qualifications

  • Currently pursuing a Bachelor’s degree in Computer Science, Software Engineering, Information Technology, or a related field.
  • Basic programming knowledge in JavaScript, TypeScript, C#, or similar languages.
  • Interest in software quality assurance, test automation, and modern development practices.
  • Familiarity with SDLC, Agile methodologies, and DevOps concepts.
  • Basic understanding of Git version control.
  • Exposure to automated testing tools such as Selenium, Playwright, Cypress, Appium, or similar is an asset.
  • Interest in mobile application testing and device automation platforms such as Kobiton is a strong asset.
  • Curiosity about AI-assisted software development tools including GitHub Copilot and Claude Code.
  • Strong analytical thinking, attention to detail, and problem-solving skills.
  • Ability to work effectively in a collaborative team environment.
  • Good communication skills and motivation to learn new technologies.

What You Will Learn

  • AI-assisted test automation
  • Using GitHub Copilot and Claude Code to draft, refine, and maintain automated tests.
  • Mobile testing on real devices
  • Validating user journeys through Kobiton across device and OS configurations.
  • CI/CD continuous testing
  • Embedding automated test execution into delivery pipelines for faster feedback.
  • Quality engineering practices
  • Strengthening test coverage, defect analysis, documentation, and automation standards.
