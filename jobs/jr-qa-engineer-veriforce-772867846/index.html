About the Role

Design and execute tests; automate QA processes

About Veriforce

Global safety and compliance software company

Full Description

Department: Technology

Employment Type: Permanent

Location: Greater Montreal Metropolitan Area, Canada

Reporting To: Director, Software Engineering

Description At Veriforce, we build innovative technology that helps create safer workplaces.

Our software supports a global network of responsible hiring clients, suppliers, contractors and partners. We take the complexity out of compliance for more than 50,000 organisations worldwide, helping them protect their people, their operations and the planet.

As a Junior Software Development Engineer in Test (SDET), you will support the delivery of reliable, high-quality software by performing manual testing and contributing to automated testing. Working alongside developers, product team members and more experienced quality engineers, you will help identify defects, validate new functionality and continuously improve our testing processes.

This is an excellent opportunity for someone early in their software testing career who wants to develop their technical skills in test automation, API testing and continuous delivery.

What That Means Day-to-day

  • Collaborate with developers, product team members and Scrum teams to understand requirements and acceptance criteria.
  • Create, document and maintain clear test cases and test scenarios.
  • Perform manual functional, regression, integration and exploratory testing.
  • Validate new features, enhancements, customisations and system integrations.
  • Identify, document and track software defects, providing clear steps for reproduction.
  • Retest resolved defects and complete regression testing before releases.
  • Support User Acceptance Testing by helping business stakeholders validate new functionality.
  • Maintain accurate documentation of test cases, test results and identified defects.
  • Develop and maintain automated test scripts with guidance from experienced team members.
  • Use tools such as Playwright or Cypress to automate repeatable application tests.
  • Review automated test results and investigate failures.
  • Help improve automated test coverage across key user journeys.
  • Learn and apply test automation standards and development best practices.
  • Contribute to the integration of automated tests within CI/CD pipelines.
  • Support the testing of APIs, data flows and system integrations.
  • Use API testing tools to validate requests, responses, error handling and data accuracy.
  • Work with developers to investigate data or integration-related defects.
  • Help ensure information remains accurate and consistent across systems and environments.
  • Participate in Agile ceremonies, including sprint planning, daily stand-ups, reviews and retrospectives.
  • Work closely with developers to identify and resolve quality issues early in the development lifecycle.
  • Contribute to discussions about test coverage, product risks and release readiness.
  • Assist with the setup and maintenance of test environments and test data.
  • Learn from experienced engineers through code reviews, pairing and technical guidance.
  • Stay informed about emerging testing tools, technologies and best practices.
  • Contribute ideas for improving testing efficiency, reliability and overall product quality.

What You’ll Need To Be Successful

  • A bachelor’s degree, diploma or equivalent training in Computer Science, Information Technology, Software Engineering or a related discipline.
  • Approximately 1–2 years of experience in software testing, quality assurance or software development.
  • Exposure to test automation through professional experience, an internship, academic projects or personal projects.
  • Experience working in an Agile or Scrum environment is beneficial.
  • A foundational understanding of software testing methodologies and the software development lifecycle.
  • Experience creating and executing manual test cases.
  • Familiarity with a test automation framework such as Playwright, Cypress, Selenium or a similar tool.
  • Basic programming or scripting ability using JavaScript, TypeScript, C#, Java or another relevant language.
  • Familiarity with API testing tools such as Postman is an advantage.
  • Basic knowledge of REST APIs, JSON and data validation.
  • Exposure to CI/CD pipelines and continuous testing concepts is beneficial.
  • Familiarity with defect tracking and test management tools such as Jira and TestRail.
  • Experience testing Salesforce or other SaaS platforms would be advantageous but is not required.
  • Strong attention to detail and a commitment to delivering high-quality work.
  • Good analytical, troubleshooting and problem-solving skills.
  • Clear written and verbal communication.
  • A collaborative approach and willingness to ask questions and learn from others.
  • Ability to organise work and manage priorities within a fast-paced environment.
  • Curiosity about how software works and enthusiasm for developing new technical skills.
  • Openness to feedback and a continuous-improvement mindset.
  • You create clear and reliable test cases based on product requirements.
  • You identify and document defects that help the team improve product quality.
  • You gradually increase your contribution to automated and API testing.
  • You collaborate effectively with developers, product team members and other quality engineers.
  • You demonstrate consistent growth in your testing, automation and technical capabilities.
