Full Description

Role: Backend Software Engineer (Python)

Location: Remote

We are hiring experienced Python Engineers to support impactful research collaborations with top AI teams. You’ll help enhance AI systems by developing real-world coding benchmarks that reflect modern engineering practices across diverse domains.

What You’ll Do:

  • Build and validate Python-based coding benchmarks using real repository issues, solutions, and tests
  • Create reliable unit and integration tests
  • Ensure consistency and scalability across benchmark tasks
  • Provide clear feedback on solution quality
  • Debug, optimize, and document code for long-term reliability

What Makes You a Strong Fit:

  • 3–10 years of backend engineering, ML engineering, or applied data science experience
  • Strong command of Python
  • Solid debugging, testing, and technical writing skills
  • Degree in Computer Science or related field

Contract Details:

  • Hourly contract ($80–$120/hr with bonus potential; median earnings ~$200/hr)
  • Part-time: 15–20 hrs/week
  • Duration: ~1 month
  • Fully remote and flexible
  • Daily payments via Stripe Connect

Application Process:

  • Resume upload
  • Short AI interview (≈15 minutes)
  • Brief coding assessment
  • Fast follow-up with next steps
