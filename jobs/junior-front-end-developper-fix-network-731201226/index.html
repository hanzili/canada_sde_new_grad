About Fix Network

Fix Network is a global leader in repair and restoration services for vehicles, homes, and businesses, supporting a growing family of locally owned and operated brands in collision repair, mechanical services, glass care, and property restoration.

With more than 2,000 points of service worldwide, Fix Network is trusted by customers and industry partners for its commitment to quality, safety, and service excellence.

Junior Front-End Developer - Job Description

Title:Junior Front-End Developer

Reports To:Software Development Manager

Location:Canada

The Junior Front End Developer assists in designing and implementing the online end-user experience as well as current and future corporate and brand website presence. Working closely with the other Front-End Developer and with the Marketing and IT teams, the Junior Front End Developer is responsible for balancing the esthetic and functionality while realizing the vision for the company’s publicly accessible websites.

Core Competencies

  • Accountability and Dependability
  • Autonomy
  • Creative and Innovative Thinking
  • Customer Focus
  • Detail Orientated and Precision
  • Development and Continual Learning
  • Problem Solving
  • Quality Orientation
  • Result Focus
  • Teamwork
  • Time Management

Job Duties

  • Coordinate tasks across different departments and stakeholders to advance projects and initiatives.
  • Work with the website owners to prioritize and implement functionality enhancements, bug fixes and design glitches.
  • Assist in creating and reviewing mobile first, state of the art website wireframes.
  • Work with the graphic design team to develop the graphic page elements.
  • Convert the website wireframes into cross-browser, cross-platform and user-friendly markup language pages.
  • Implement client-side code using scripting languages such as HTML5, JavaScript and jQuery.
  • Create and maintain cascading stylesheets (CSS) to ensure design consistency across all websites.
  • Build reusable code to facilitate the implementation of visual standards across all websites and optimize project delivery speed.
  • Collaborate with Marketing to implement and maintain Search Engine Optimization (SEO) and Search Engine Marketing (SEM) website requirements.
  • Perform onsite optimizations to help improve websites’ crawlability, indexability, faster page load times, cross browser compatibility and search engine rankings.
  • Ensure that the corporate and brand design guidelines are consistent throughout the websites.
  • Perform website content updates where the CMS fails to allow site owners to maintain the content themselves.
  • Collaborate with back-end developers to implement pages with dynamic content and service side functionality.
  • Assist in testing and troubleshooting bugs and anomalies with website pages and functionality.
  • Collaborate with the infrastructure team for production code releases and infrastructure related performance issues.
  • Stay up to date on new emerging web and design technologies.

Requirements

  • Bachelor or college degree in Computer Science, Web Development, Software Development or equivalent.
  • Minimum 1 year of related experience or a completed internship.
  • Knowledge of shopping platform Shopify from the administrative point of view is essential.
  • Knowledge of Agile development methodologies, tools and best practices.
  • Knowledge of web development technologies such as HTML5, CSS, JavaScript, PHP, JSON and jQuery.
  • Knowledge of object-oriented software development languages.
  • Knowledge of Microsoft Azure Services, Visual Studio and development tools.
  • Knowledge of Search Engine Optimization (SEO), Search Engine Marketing (SEM), Google Analytics and Google Tag Manager.
  • Knowledge of Content Management System (CMS) such as WordPress.
  • Knowledge of Web Content Accessibility Guidelines (WCAG).
  • Effective verbal and written communication skills.
  • Able to work well under pressure and meet set deadlines.
  • Demonstrated aptitude for learning new technologies.

Working Conditions

  • Occasional overtime required.
  • Business casual dress code.
  • Flexible working schedule.
