Job Description

What is the opportunity?

We are seeking a motivated and enthusiastic Junior DevOps Engineer to join our team. This is an excellent opportunity for someone early in their DevOps career to gain hands-on experience with modern cloud technologies, automation tools, and security practices. The successful candidate will work closely with senior team members to support production systems, learn infrastructure management, and develop skills in CI/CD, containerization, and security vulnerability management. The ideal candidate will have foundational knowledge in Azure Cloud, Linux systems, basic scripting abilities, and a strong eagerness to learn and grow in the DevOps field with an automation-first mindset.

What will you do?

  • Collaborate with development teams to support production deployments.
  • Participate in design review process of new application features to understand infrastructure requirements.
  • Assist in managing and executing Terraform Enterprise (TFE) pipelines under supervision.
  • Support deployment and management of infrastructure changes, including provisioning and configuration of servers, networks, and databases.
  • Assist in developing and maintaining CI/CD pipelines using GitHub Actions, Azure Pipelines, and other relevant tools.
  • Support containerization efforts using Docker and assist with container deployment in Kubernetes and Azure Kubernetes Service (AKS).
  • Learn and assist with OpenShift Container Platform (OCP) environments.
  • Learn and assist with SAST (Static Application Security Testing) and DAST (Dynamic Application Security Testing) tool integration.
  • Support vulnerability management activities using SonarQube and other security scanning tools.
  • Monitor system performance and report anomalies to senior engineers.
  • Work with cross-functional teams (cloud, security, TFE) to learn enterprise processes and support infrastructure needs.
  • Help ensure compliance with security, scalability, and reliability standards.
  • Participate in on-call rotations with guidance from senior team members.
  • Develop and maintain documentation of infrastructure, deployments, and other DevOps-related processes and procedures.
  • Learn infrastructure automation using tools such as Terraform and Prometheus.
  • Develop scripting and automation skills using Python, Bash, or PowerShell with an automation-first mindset.
  • Continuously learn new technologies and stay up to date with the latest trends and best practices in DevOps, cloud computing, and containerization.

What do you need to succeed?

  • Hands-on experience developing and supporting cloud based applications. (Spring Boot and React   or similar front-end frameworks
  • Some knowledge in Node.js or Python, and SQL with familiarity in relational databases
  • Knowledge building and consuming RESTful APIs with multi-system integration
  • Exposure to CI/CD pipelines, automated testing concepts, and Agile delivery practices
  • Basic knowledge of cloud platforms (OpenShift, AWS S3, or Azure) and comfort working with different environments
  • Fast learner who is results-oriented, self-motivated, and effective working both independently and in a team
  • Knowledge on using AI and automation

Must-have

  • Bachelor's degree in Computer Science, Information Technology, or a related field.
  • 1-3 years of experience in a DevOps, IT operations, system administration, or similar role.
  • Basic understanding of Azure Cloud services, including Azure DevOps, Azure Kubernetes Service (AKS), Azure Virtual Machines, etc.
  • Foundational knowledge in areas such as cloud computing, networking, and database management.
  • Exposure to infrastructure as code (IaC) tools such as Terraform or ARM templates.
  • Basic understanding of CI/CD concepts and exposure to relevant tools (e.g., Jenkins, GitHub Actions, Azure Pipelines).
  • Basic understanding of Linux operating systems and command-line operations.
  • Basic scripting skills in Python, Bash, or PowerShell.
  • Interest in learning automation practices and developing an automation-first mindset.
  • Basic understanding of application security concepts including SAST and DAST.
  • Familiarity with vulnerability scanning tools like SonarQube or willingness to learn.
  • Strong problem-solving abilities and analytical thinking.
  • Strong collaboration and communication skills.
  • Familiarity with Agile development methodologies and version control systems such as Git.
  • Self-motivated with a strong desire to learn new technologies.
  • Good attention to detail and documentation practices.
  • Basic knowledge on how to use AI tools and automations

Nice-to-have

  • Exposure to Azure cloud platform and Azure services.
  • Basic knowledge of security best practices and compliance frameworks.
  • Basic understanding of containerization technologies such as Docker.
  • Exposure to Kubernetes or OpenShift Container Platform (OCP).
  • Familiarity with monitoring and logging tools such as Prometheus, Grafana, or Dynatrace.
  • Microsoft Certified: Azure Fundamentals or Azure Administrator Associate certification.
  • Exposure to automation tools such as Ansible, Puppet, or Chef.
  • Basic understanding of networking protocols and architectures.
  • Personal projects or contributions to open-source projects demonstrating DevOps skills.
  • Any relevant cloud or DevOps certifications or willingness to obtain them.
