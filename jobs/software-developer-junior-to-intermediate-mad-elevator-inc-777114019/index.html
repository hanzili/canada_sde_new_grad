About the Role

Develop web and desktop apps; fix bugs

About MAD Elevator Inc

Mississauga-based software firm with ERP integrations

Full Description

Primary Function:

As a Junior Software Developer, you will collaborate with our Principal Software Developer to build, maintain, and enhance code for both existing and new projects.

The ideal candidate should be self driven and have a systematic problem-solving approach and strong troubleshooting skills. The candidate should have exceptional communication skills, previous experience in a start-up environment, be proactive about improving quality, and one who learns quickly and stays informed regarding industry trends.

Qualifications and Educational Requirements:

  • Bachelor's degree in Computer Science, Computer Engineering, or equivalent work experience
  • Co-op work experience preferred
  • Experience working on web and desktop applications
  • Familiarity with back-end systems and various system architectures
  • Knowledge of software patterns and strong written and verbal communication skills

Preferred Qualifications and Experience:

  • Proficiency in TypeScript, JavaScript, and C#
  • Experience building web applications with Next.js and React
  • Experience with Python for back-end services and automation
  • Experience with MVC, MVP, and MVVM architectures
  • Exposure to WPF and WinForms projects
  • Familiarity with SQL Server and PostgreSQL databases (MySQL a plus)
  • Experience integrating with ERP systems via REST and GraphQL APIs
  • Familiarity with source code management and branching techniques (Git preferred)
  • Experience using AI-assisted development tools (e.g. Claude Code, GitHub Copilot)
  • Exposure to HTML5 and GraphQL
  • Demonstrated ability to debug production systems and trace issues across application, integration, and database layers

Assets:

  • Experience working with cloud platforms such as AWS and Azure
  • Familiarity with containerization (Docker) and orchestration tools
  • Understanding of DevOps practices and CI/CD pipelines (e.g. Aws CodeBuild)
  • Exposure to Elasticsearch or other search/indexing technologies
  • Experience with Electron desktop applications

Responsibilities, Skills, and Competencies:

  • Collaborate with an experienced full-stack software developer to maintain and enhance existing projects by adding new features or debugging based on tickets.
  • Work on new projects, participating in the development lifecycle from requirements gathering to deployment.
  • Write well-designed, reusable, testable, and efficient code.
  • Troubleshoot and resolve issues.
  • Participate in peer code reviews.
  • Stay informed about industry trends and continuously improve your skills.
  • Demonstrate strong problem-solving abilities and a systematic approach.
  • Proactively contribute to quality improvement initiatives.
  • Learn quickly and adapt to new technologies and frameworks.
  • Build and maintain web applications using Next.js, TypeScript, and React, such as customer-facing sales and order-tracking portals.
  • Develop and maintain desktop applications in C#/.NET, including WinForms and WPF across .NET Framework and .NET 8.
  • Build and consume REST/GraphQL APIs and data-sync services that integrate internal applications with ERP systems.
  • Write and optimize SQL across ERP and application databases, including SQL Server and PostgreSQL queries and stored procedures.
  • Work with containerized services and cloud deployment through CI/CD pipelines, including Docker, AWS, and GitHub Actions.
  • Use AI-assisted development tools responsibly to accelerate development, debugging, and code review while validating outputs before implementation.
  • Contribute to ongoing modernization of legacy applications while keeping business-critical systems reliable.
  • Other duties as assigned.
  • Able to lift up to 15 lbs; may work in hot areas 5%, noise 0%.
  • Ensure adherence to Health and Safety as well as active participation in 5S activities in the work area.

Measures of Success / KPI Metrics:

  • Feature & Project Delivery
  • Deliver assigned features, enhancements, and new-project work on schedule and to agreed acceptance criteria across web (Next.js/TypeScript) and desktop (.NET/C#) applications.
  • Break work into reviewable, testable increments and meet sprint/board commitments consistently.
  • Production Stability & Issue Resolution
  • Diagnose and resolve ticketed issues within agreed severity-based timeframes, tracing root cause across application, integration, and database layers.
  • Deliver durable fixes rather than repeat patches — measured by low recurrence of the same defect (e.g. ERP invoicing and ship-posting issues).
  • Code Quality & Peer Review
  • Maintain code quality through peer review, adherence to team standards, and appropriate test coverage.
  • Provide timely, constructive reviews and apply sound judgment with AI-assisted tools — validating output, not shipping it unchecked.
  • ERP Integration & Data Reliability
  • Ensure APIs and data-sync services post correctly to and from ERP systems (orders, shipments, invoicing, inventory).
  • Optimize and maintain SQL across ERP and application databases for correctness and performance.
  • Deployment & Operational Readiness
  • Ship changes through CI/CD pipelines cleanly, with successful builds and low rollback/hotfix rates.
  • Support reliable operation of containerized and cloud-deployed services.
  • Technical Documentation & Knowledge Sharing
  • Create and maintain current documentation for systems, integrations, and fixes so knowledge isn't siloed to one person.
  • Keep work traceable in Jira/Confluence with accurate runbook and recovery steps.
  • Learning, Modernization & Continuous Improvement
  • Ramp on the existing codebase and adopt new frameworks/tools quickly, contributing to modernization (e.g. legacy .NET to .NET 8).
  • Proactively surface and act on quality and process improvement opportunities.
  • Collaboration & Stakeholder Support
  • Translate business needs from operations, finance, engineering, and shipping teams into working technical solutions.
  • Communicate clearly and follow through, giving internal stakeholders a responsive, positive experience.

This position is located at 6635 Ordan Drive in Mississauga, ON. Hours are typically 8:00am to 4:30pm.

We are open to candidates at both the junior and intermediate levels. Compensation will be based on experience, skills, and qualifications.

Pay: $72,000 - $95,000.00

This is a Full-time, Salary position.
