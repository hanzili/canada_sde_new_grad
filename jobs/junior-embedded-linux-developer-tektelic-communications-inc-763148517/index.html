About the Role

Develop embedded Linux software for gateways

About TEKTELIC Communications Inc.

IoT gateway leader, global deployments

Full Description

Build the backbone of global IoT connectivity.

TEKTELIC is a world leader in LoRaWAN gateways, sensors, and end-to-end IoT solutions. Our KONA gateway portfolio powers mission-critical deployments across smart cities, agricultural, industrial, and enterprise IoT. We are looking for a motivated Junior Embedded Linux Developer to help build and support the next generation of our carrier-grade gateway products.

This role is ideal for an early-career developer who enjoys working close to the hardware, wants to grow strong embedded Linux skills, and is excited to contribute to reliable IoT systems used around the world.

Responsibilities

  • Develop, test, and maintain embedded Linux software for TEKTELIC’s KONA gateways under the guidance of senior developers.
  • Work hands-on with embedded Linux systems, including user-space applications, system services, device interfaces, and production configuration.
  • Support board bring-up, hardware verification, and troubleshooting activities in collaboration with hardware and systems teams.
  • Build and use cross-compilation toolchains, Yocto/OpenEmbedded SDKs, and ARM-based development environments.
  • Investigate defects, reproduce field issues, analyze logs, and help deliver maintainable fixes for production gateway software.
  • Create and update design documentation, test plans, release notes, and technical support information.
  • Develop and execute manual and automated tests using Python, Bash, and other scripting tools.
  • Contribute to continuous improvement of build systems, CI/CD pipelines, automated testing, and development workflows.

Qualifications

  • Bachelor’s degree, diploma, or equivalent experience in Computer Science, Computer Engineering, Electrical Engineering, Software Engineering, or a related field.
  • 0-3 years of experience developing embedded systems, embedded Linux software, or closely related software projects.
  • Strong foundation in C programming.
  • Scripting experience in Python, Lua, Bash, or similar languages.
  • Working knowledge of Linux systems, including command-line tools, processes, file systems, networking basics, and Bash scripting.
  • Basic understanding of IP networking concepts and serial communication interfaces.
  • Experience with Git or other source control systems.
  • Ability to work in a team environment, participate in code reviews, learn from feedback, and communicate clearly in writing and verbally.

Desirable Skills

  • Familiarity with LoRaWAN or other LPWAN/IoT communication technologies.
  • Familiarity with cross-compilation, embedded build environments.
  • Understanding of hardware interfaces such as I2C, SPI, GPIO, UART, USB, or Ethernet.
  • Experience with continuous integration systems such as Jenkins, GitLab CI, or similar tools.
  • Interest in security best practices for embedded Linux systems.
