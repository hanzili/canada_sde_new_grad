About the Role

About CGI

Global IT services and consulting leader

Full Description

CGI is seeking an Associate DevOps Consultant to join our Cloud Engineering team and support the modernization, automation, and continuous delivery of cloud-native applications and infrastructure. This is an exciting opportunity for a junior technology professional with 1 to 3 years of experience, ideally with a strong software development background and approximately 2 years of hands-on development experience, who is looking to grow a career in DevOps. In this role, you will work alongside experienced consultants, developers, and platform teams to build and enhance CI/CD pipelines, automate infrastructure, and support cloud environments across AWS and Azure. You will gain hands-on experience with cloud engineering, Infrastructure as Code, deployment automation, observability, and production support through mentorship and real-world project work. This is a full-time contract position through December 2026, with the possibility of extension or conversion to a permanent role based on business needs. The role is available in any of our Atlantic Canada offices, including Halifax, NS; Moncton or Fredericton, NB; Stratford, PEI; and St. John's, NL.

Your future duties and responsibilities

  • Collaborate with application development, cloud engineering, and platform teams to support cloud-based application delivery and automation.
  • Build, maintain, and enhance CI/CD pipelines for cloud-native applications.
  • Support automated build, test, deployment, and release processes using tools such as Jenkins, GitHub Actions, GitLab CI/CD, Azure DevOps, or similar platforms.
  • Contribute to Infrastructure as Code (IaC) solutions using Terraform, ARM, CloudFormation, Ansible, or similar technologies.
  • Participate throughout the software development lifecycle, including planning, development, testing, deployment, release support, and documentation.
  • Apply software engineering best practices, including version control, code reviews, reusable scripting, testing, and automation.
  • Collaborate with developers to understand application architecture, deployment requirements, configuration needs, and environment dependencies.
  • Troubleshoot deployment issues, pipeline failures, application environment challenges, and cloud infrastructure incidents.
  • Participate in root cause analysis and contribute to continuous improvement initiatives.
  • Develop and maintain technical documentation for deployment processes, automation workflows, and operational procedures.

Required qualifications to be successful in this role

  • Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
  • 1 to 3 years of professional experience in software development, DevOps, cloud engineering, infrastructure support, or a related technical role.
  • Preferred: Approximately 2 years of hands-on software development experience with exposure to DevOps practices.
  • Experience developing applications using one or more programming or scripting languages such as Python, Java, JavaScript, C#, Go, Bash, or PowerShell.
  • Experience using Git-based source control platforms such as GitHub, GitLab, or Bitbucket.
  • Solid understanding of the Software Development Life Cycle (SDLC), including development, testing, build, release, and deployment.
  • Familiarity with CI/CD concepts and tools such as Jenkins, GitHub Actions, GitLab CI/CD, Azure DevOps, CloudBees, or similar platforms.
  • Basic understanding of cloud platforms such as AWS or Microsoft Azure.
  • Exposure to Infrastructure as Code (IaC) and configuration management tools such as Terraform, ARM, CloudFormation, or Ansible.
  • Familiarity with Docker and Kubernetes is considered an asset.
  • Exposure to microservices, APIs, and modern application deployment patterns is an asset.
  • Strong analytical and troubleshooting skills with the ability to investigate issues across applications, pipelines, and infrastructure.
  • Excellent communication and collaboration skills, with the ability to work effectively across cross-functional teams.
  • A passion for automation, continuous improvement, and learning modern DevOps and cloud engineering practices.
