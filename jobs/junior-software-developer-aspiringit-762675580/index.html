Full Description

Job Title: Junior Software Developer

Location: Toronto, Canada (Remote – once‑a‑quarter office visit)

Job Description

We are looking for a Junior Software Developer with 1 year of hands‑on experience in Java and AWS to join our growing engineering team. This is a remote role based in Canada, with an in‑office visit required once per quarter for team collaboration.

Key Responsibilities

• Develop, test, and maintain backend applications using Java

• Assist in building and deploying cloud‑based solutions on AWS

• Write clean, efficient, and well‑documented code

• Collaborate with senior developers on design, development, and troubleshooting

• Participate in code reviews and agile ceremonies

• Support application monitoring, debugging, and minor enhancements

Required Skills & Qualifications

• 1+ year of hands‑on experience with Java

• 1+ year of experience working with AWS (EC2, S3, Lambda, or similar)

• Basic understanding of REST APIs and backend development

• Familiarity with Git or other version control tools

• Strong problem‑solving skills and willingness to learn

• Must be legally eligible to work in Canada

Nice to Have

• Exposure to Spring / Spring Boot

• Basic SQL or NoSQL database knowledge

• Understanding of CI/CD pipelines

• Agile/Scrum experience

Work Model

• Remote (Canada‑based)

• Quarterly office visit in Toronto required
