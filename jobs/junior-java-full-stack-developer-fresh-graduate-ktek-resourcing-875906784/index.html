Full Description

Title : Junior Java Full Stack Developer (Fresh Graduate)

Location: Toronto, ON

Position Type: Full Time

Job Summary

We are looking for enthusiastic and motivated Fresh Graduates who are passionate about software development and eager to build a career in Java Full Stack Development. The candidate will work as part of an Agile development team to design, develop, test, and support enterprise applications using Java, Spring Boot, Angular, REST APIs, and Oracle databases under the guidance of senior team members.

Key Responsibilities

  • Participate in the development and maintenance of enterprise applications using Java and related technologies.
  • Assist in building and enhancing Microservices and RESTful APIs.
  • Develop user interfaces using Angular and modern web technologies.
  • Write clean, maintainable, and efficient code following coding standards.
  • Support database development activities using Oracle SQL.
  • Participate in unit testing, defect fixing, and application support activities.
  • Collaborate with Business Analysts, Developers, QA teams, and stakeholders.
  • Participate in Agile ceremonies including sprint planning, stand-ups, and retrospectives.
  • Learn and adopt DevOps, CI/CD, security, and software engineering best practices.
  • Contribute to documentation and knowledge-sharing activities.

Required Technical Skills

Core Technologies

  • Knowledge of Java, Object-Oriented Programming (OOP), and Core Java concepts.
  • Understanding of Spring Boot and REST API development.
  • Basic understanding of Microservices Architecture.
  • Familiarity with SQL and relational databases (Oracle preferred).
  • Understanding of Hibernate/JPA concepts.
  • Knowledge of Angular, HTML, CSS, and JavaScript/TypeScript.
  • Understanding of software design principles and coding best practices.

Development Tools

  • Familiarity with Git or other Version Control Systems.
  • Understanding of Unit Testing concepts (JUnit preferred).
  • Exposure to CI/CD concepts and DevOps practices.

Nice to Have

  • Academic or internship experience with Java Full Stack projects.
  • Knowledge of Single Page Applications (SPA).
  • Exposure to Docker, Kubernetes, or containerization concepts.
  • Familiarity with Cloud platforms (AWS or Azure).
  • Knowledge of automation tools such as Ansible.
  • Exposure to monitoring and logging tools.

Soft Skills

  • Strong analytical and problem-solving skills.
  • Good communication and interpersonal skills.
  • Willingness to learn and adapt to new technologies.
  • Ability to work effectively in a team environment.
  • Positive attitude and eagerness to take ownership of tasks.

Educational Qualifications

  • Bachelor's Degree in Computer Science, Information Technology, Software Engineering, or related discipline.
  • Recent graduates (2025 or 2026 pass-outs preferred).
  • Strong academic record with coursework in programming, databases, web technologies, or software engineering.

Preferred Candidate Profile

  • 0–2 years of experience (including internships, co-op programs, academic projects, or training).
  • Hands-on projects using Java, Spring Boot, Angular, or related technologies.
  • Passion for software development and continuous learning.
  • Knowledge of Banking or Financial Services domain is an added advantage.

Mandatory Skills Summary

  • Java
  • Spring Boot
  • REST APIs
  • SQL (Oracle preferred)
  • Angular
  • Git
  • Object-Oriented Programming

Good to Have

  • Microservices
  • Hibernate/JPA
  • CI/CD Concepts
  • Docker/Kubernetes
  • AWS/Azure
